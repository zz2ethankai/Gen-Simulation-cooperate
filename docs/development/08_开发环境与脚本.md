## 开发容器用法（isaac_dev.sh）

- 用途：代码开发、shell 访问、import 与轻量检查的隔离容器；镜像复用当前 Isaac 6.0.1 + CuRobo v2，挂载仓库到 /workspace，强制 INTERNDATA_AUTOSTART_LAUNCHER=0、INTERNDATA_RUN_IMPORT_CHECKS=0、LIVESTREAM=0、launcher 参数为空（isaac_dev.sh:162-167），不启动 launcher.py。

### 六个动作
- shell（默认动作）：启动容器并进入交互 Bash，用于日常开发；`scripts/docker/isaac_dev.sh shell --gpu 0`（首次需要 `--build` 重建镜像时追加）。
- start：后台启动容器，不进入 shell；`scripts/docker/isaac_dev.sh start --gpu 1`；容器状态 ready 后可通过 exec 使用。
- exec：在容器内 /workspace 运行单条命令，用于非交互检查；`scripts/docker/isaac_dev.sh exec -- python -V` 或 `scripts/docker/isaac_dev.sh exec -- bash -lc 'pwd; python -V'`。
- status：显示容器状态；`scripts/docker/isaac_dev.sh status`。
- logs：查看容器日志；`scripts/docker/isaac_dev.sh logs --follow`（默认 tail 100 行，INTERNDATA_DEV_LOG_TAIL 可调）。
- stop：停止并删除 dev compose project（compose down --remove-orphans），释放 GPU；`scripts/docker/isaac_dev.sh stop`。
- 常用选项：--gpu ID、--stack-id ID（隔离容器名与缓存）、--isaac-cpus COUNT（CPU 配额）、--compose-file PATH、--build。GPU 可用 INTERNDATA_DEV_GPU、stack 可用 INTERNDATA_DEV_STACK_ID 环境变量覆盖。
- 实现细节：shell 与 exec 都经 /entrypoint.sh 运行命令（run_shell 第 249 行、run_command 第 258-259 行），保证 Isaac/CUDA 运行时环境变量存在；start 动作由 start_container 复用 up_simbox_isaac.sh 启动（第 215 行），wait_until_running 轮询容器状态（218-238）。

### 命名与缓存
- 默认容器 isaac-dev-dev、compose project simbox-isaac-dev-dev；--stack-id 自定义时对应变化。缓存/日志在 output/isaac-dev/<stack-id>/ 下：cache/main、cache/computecache、logs、config、data、pkg（isaac_dev.sh:169-174），不在根属的 .docker/isaac-sim/ 树。

### 验证入口的关系
- up_simbox_isaac.sh：无 TASK_CONFIG 时只启动 Isaac 容器；设置 TASK_CONFIG 后由同一入口生成运行契约、启动容器、docker wait 读退出码、校验日志 marker 并写入 docker_runtime.json；参数包括 --task-config / --stack-id / --gpu / --launcher-config / --launcher-extra-args / --isaac-cpus；任务验证栈的 Isaac 缓存落在 ../.docker/isaac-sim/<stack_id>/。
- 场景 4 验证 wrapper：整批任务验证时优先使用；单任务调试使用 `TASK_CONFIG=... scripts/docker/up_simbox_isaac.sh`。
- isaac_dev.sh：开发容器，与任务验证栈完全隔离（独立 compose project 与缓存目录），不占用验证容器；在跑任务验证时若 GPU 资源竞争，先停止 dev 容器。
- 开发者容器不是任务验证：任务成功必须由 up_simbox_isaac.sh 的 TASK_CONFIG 模式 / 验证 wrapper 给出 "Task is successful, mode=plan_with_render" 且无 "[LmdbLogger] Episode failed"，视频或缺失 traceback 不算数。
